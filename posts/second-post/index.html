API‑Token#

泄露后果：别人盗用token消耗账户余额，账号可能被风控封禁。

HTTP协议#

GET与POST区别#

  1. GET：参数放在URL地址栏，多用于获取页面，不适合传密码。
  2. POST：参数放在请求Body请求体，适合提交登录表单。

常见请求头的作用#

  • User‑Agent：告诉服务器客户端浏览器信息
  • Cookie：浏览器存储身份凭证，每次请求自动携带
  • Referer：记录请求从哪个页面跳转而来

鉴权#

  1. Session：身份数据保存在服务端，Cookie仅存放SessionID编号。
  2. JWT：身份信息编码在Token字符串内部，不需要服务器存储会话。

状态码的含义#

  • 200：请求成功
  • 302：重定向跳转
  • 403：权限不足禁止访问
  • 5xx：服务器/代理出错（如502）

任务7：前端三件套 HTML / CSS / JavaScript#

  • HTML：网页骨架。
  • CSS：页面样式美化。
  • JavaScript：浏览器本地交互逻辑。

F12开发者工具#

F12开发者工具核心面板：

  1. 元素(Elements)：查看修改HTML、CSS
  2. 控制台(Console)：运行JS，查看报错
  3. 网络(Network)：浏览器自带抓包，仅能观察，不能修改已发送的请求。 （os:部分使用AI）
